## Note on `editor-guide.md`

This one is a test, not just a document.

**R14** says the correct action must be the easiest action. The way to check that is to hand a non-technical person this guide and three real tasks. If they reach for a workaround, the *structure* has failed — go and fix the structure. Do not fix the guide.
